# Life Dashboard

Project Coding Camp - To-Do List Life Dashboard

## Features
- Real-time clock, date, and greeting
- Custom user name
- Pomodoro timer with custom duration
- Start, pause, and reset timer
- To-do list with add, edit, complete, delete
- Duplicate task prevention
- Task sorting
- Local Storage persistence
- Quick links
- Light/Dark mode

## Folder Structure
index.html
css/style.css
js/script.js

Open index.html in a modern browser to run the project.
